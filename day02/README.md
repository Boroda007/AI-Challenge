# День 2: Формат ответа

Минималистичный ИИ-чат с веб-интерфейсом для наглядного сравнения работы языковых моделей с разным уровнем контроля. Приложение позволяет отправить один запрос и одновременно увидеть два результата: стандартный «свободный» ответ ИИ и жестко ограниченный по формату и длине.

## Возможности

- **Две колонки чата**: «Без ограничений» (левая) и «С ограничениями» (правая)
- **Панель настроек** с инженерными параметрами:
  - Формат ответа (Text / JSON)
  - Длина (5–1000 токенов)
  - Стоп-символ
  - Температура (0–2)
- **Промпт-инжиниринг**: системный промпт
- **Бейджи параметров**: отображение применённых ограничений и причины остановки
- **Счётчик токенов**: количество токенов в ответе (completion tokens) под каждым ответом ИИ
- **Параллельные вызовы**: два запроса к LLM выполняются одновременно

## Зависимости
Основные пакеты, зафиксированные в `requirements.txt`:
- `fastapi` — веб-фреймворк.
- `uvicorn` — ASGI-сервер для запуска приложения.
- `openai` — SDK для отправки запросов к OpenAI-совместимым API.
- `python-dotenv` — считывание конфигурации из файлов `.env`.
- `python-multipart` — обработка данных из HTML-форм чата.
- `markdown` — преобразование текста с разметкой Markdown в формат HTML.

## Переменные окружения
Настройки считываются из локального файла **`.env`**, расположенного непосредственно в папке `day02`.

### Список переменных в `.env`:
- `BASE_URL` — эндпоинт API облачного провайдера / ИИ-роутера.
- `API_KEY` — ваш личный токен доступа.
- `MODEL_NAME` — техническое название используемой модели.

*Пример содержимого файла `day02/.env`:*
```text
BASE_URL="https://example.com"
API_KEY="your_secret_api_key"
MODEL_NAME="your-model-name"
```

## Как развернуть и запустить

### 1. Подготовка окружения (в папке `day02`)
```bash
# Создание виртуального окружения
python3 -m venv venv

# Активация виртуального окружения
source venv/bin/activate  # Для Linux / macOS
# venv\Scripts\activate  # Для Windows

# Установка зависимостей
pip install -r requirements.txt

# Создание файла .env с шаблонными значениями
echo 'BASE_URL="https://example.com"' >> .env
echo 'API_KEY="your_secret_api_key"' >> .env
echo 'MODEL_NAME="your-model-name"' >> .env
```

### 2. Запуск приложения

Конфигурацию можно передать двумя способами:

- **Через локальный файл `.env`:**
  Заполните файл `.env` в папке и запустите сервер:
  ```bash
  python app.py
  ```

- **Через терминал «на лету» (переопределение настроек):**
  Вы можете временно переопределить любую переменную, передав её прямо в момент вызова команды:
  ```bash
  BASE_URL="https://custom-router.com" API_KEY="custom_api_key_placeholder" MODEL_NAME="custom-llm-model-name" python app.py
  ```

После запуска откройте в браузере адрес: **`http://127.0.0.1:8000`**.

## API

### `GET /`
Отдаёт HTML-страницу чата.

### `POST /api/chat`
Принимает JSON и возвращает ответы от двух параллельных вызовов LLM.

**Запрос:**
```json
{
  "message": "Привет!",
  "free_history": [...],
  "controlled_history": [...],
  "constraints": {
    "max_tokens": 50,
    "temperature": 0.7,
    "system_prompt": "Ты робот-аналитик..."
  }
}
```

**Ответ:**
```json
{
  "free_response": {
    "content": "<p>Привет! Как я могу помочь?</p>",
    "usage": { "prompt": 10, "completion": 15, "total": 25 }
  },
  "controlled_response": {
    "content": "<p>Привет.</p>",
    "finish_reason": "stop",
    "applied_params": { "Длина": 50, "Температура": 0.7 },
    "usage": { "prompt": 25, "completion": 5, "total": 30 }
  }
}
```

**Поля `constraints`:**
| Поле | Описание |
|------|----------|
| `max_tokens` | Максимальная длина ответа в токенах |
| `temperature` | Температура генерации (0–2) |
| `stop` | Стоп-символ |
| `response_format` | `{ "type": "text" }` или `{ "type": "json_object" }` |
| `system_prompt` | Системный промпт |
| `reasoning_effort` | Рассуждения отключены (`none` по умолчанию). Допустимые: `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max` |
